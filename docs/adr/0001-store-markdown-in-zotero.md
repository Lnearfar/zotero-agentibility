# Store Markdown full text in Zotero

Each converted Literature Item has exactly one imported Zotero child attachment named `fulltext.md`, titled `Markdown Full Text`, marked with `zotero-cli:fulltext`, and synchronized unchanged. Zotero Notes and Annotations are never Full Text, regardless of their content or tags. It is a Zotero-owned stored copy, not a linked file or symbolic link. Zotero remains responsible for synchronizing stored attachments; this project does not implement a separate synchronization engine. Conversion is external, converter-agnostic, and run only on explicit user intent; the project validates and imports the resulting Markdown. Extracted image files are not retained or rewritten, and figure verification returns to the Source Document. Replacement validates the new attachment before moving the old one to Zotero Trash; conflicts require explicit selection rather than filename or timestamp heuristics. Once present, the marked Markdown remains canonical until an explicit `fulltext replace` or removal; PDF changes do not invalidate it.
