# Base the CLI on cli-anything-zotero

This project starts from `PiaoyangGuohai1/cli-anything-zotero` main at commit `f621952f3645546573d622440cbf707320f7a35f` under Apache-2.0, preserving its safe Zotero workflows and tests instead of rebuilding them. Direct Zotero SQLite writes, the public arbitrary-JavaScript command, cloud-LLM analysis, and DOCX/LibreOffice automation are removed; BibTeX and CSL exports remain. Session handling, bridge authentication, and semantic indexing are replaced to meet this project's multi-agent, local-only, and Markdown-first rules. Semantic-search behavior is additionally derived from `54yyyu/zotero-mcp` 0.6.2 under MIT, while cloud embeddings, Notes/Annotations, background updates, reranking dependencies, and the old index are excluded by the project's recorded local-ONNX and source-grounding decisions. The upstream license and attribution are retained and modified files are identified. The umbrella repository contains three components: `za-cli/` with Python namespace `za_cli` and executable `za-cli`, `zotero-extension/`, and `skills/research-with-zotero/`.
