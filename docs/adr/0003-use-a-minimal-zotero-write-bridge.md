# Use a minimal Zotero write bridge

A small Zotero plugin exposes authenticated loopback operations used only by fixed CLI commands, including importing and safely replacing `fulltext.md` on an existing Literature Item. The Local API is read-only, Connector endpoints cannot perform this operation for an arbitrary existing parent, and direct SQLite/storage writes are unsafe; using Zotero's APIs preserves its transactions and configured file-sync behavior. The public arbitrary-JavaScript command and unauthenticated eval surface from upstream are not retained. On first startup, the manually installed Extension generates a per-machine random bearer token at `~/.config/zotero-agentibility/bridge-token` with mode `0600`; the CLI reads that shared file. The XPI contains no static token. Fixed write operations remain audit-logged. The bridge is not an MCP interface.
